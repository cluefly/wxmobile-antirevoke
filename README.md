## 功能特性

- **消息防撤回**：别人撤回消息时，这台手机已经收到的消息保持原样，并在它下方补一条红色的「【已撤回】」系统提示行。
- **自身撤回不受影响**：自己主动发出的撤回照常显示撤回状态。
- **公众号消息不拦截**：公众号等推送服务保持微信原有行为。
- **微信控制**：支持在界面中直接停止或启动微信（需要 Root 权限）。
- 符号适配微信 8.0.78（版本差异较大时在 Xposed 日志提示 miss，不影响微信正常收发消息）。

## 作用域

在 Xposed 管理器（如 Vector / LSPosed）中启用本模块，作用域勾选：

- `com.tencent.mm`（微信）

## 构建

构建脚本自动识别系统环境中的 JDK 17 与 Android SDK 34：

```bash
./build.sh
```

生成产物位于 `dist/` 目录下：
- `dist/AntiRevoke.apk`：模块应用 APK
- `dist/wx-antirevoke-0.3.zip`：APatch / Magisk 刷机模块 Zip 包
